## 0. 这是什么

雅思 6.5 备考工作区：词库（md/xlsx）+ 自建背单词应用（`word-app/`，间隔重复记忆法）。
不做什么：不放备考之外的内容；词库数值与记忆状态以 `word-app` 内 IndexedDB 运行时为准（文档只记口径，不复制实时数值，§2.1）。

## 1. 铁律（每次工作必须遵守）

1. 认事实先读 `项目现状.md`（唯一真相源）——其他文档里的数字都可能是旧的。
2. 动手前先读 `项目进度.md` 的最近变更与下一步。
3. 碰字段/公式/阈值（DB schema、SRS 间隔参数、词表字段）先查 `数据字典.md`（契约）。
4. 每次工作结束前更新 `项目进度.md`（变更日志）、`项目现状.md`（事实源）与受影响契约，并更新各自「最近更新」日期。
5. **每次工作前**：快速核对 `docs/项目文档体系规范.md` §12.5 五条升级触发器（版本重检，待办首行固定项）。

## 3. 红线

- 数值类事实只住 L1（`项目现状.md`），其他文档引用不复制（§2.1）。
- 经验/事实条目必须有真实来源或显式标「待验证」（§11.1）；**经验库条目禁止「待验证」入库（§12.4.1）**。
- 同源双份必须互相点名并同时修改（§2.7）：`docs/` 规范副本与主线正典、`word-app/data/` 词表与根目录词表 md（见数据字典 §5）。
- 敏感信息（密码/密钥/令牌/手机号/完整内网拓扑）禁止入文档（§3.6）。
- `word-app/node_modules/`、`word-app/dist/` 不进 git（`.gitignore` 已覆盖）。

## 4. 更新规则

- 变更日志倒序、同日合并、固定「同日杂项」小节（§2.3）。
- 提交信息：`类型(范围): 一句话动机`（§4.1）。
- 治理文档（README/现状/进度/数据字典）改动同步各自「最近更新」日期。
- 规范条款改编必须登记 E（§12.3.2）；本副本当前无本地改编（正文逐字继承 fork 锚点）。

## 5. 运行 word-app

```
cd word-app
pnpm install        # 首次；allowBuilds 已放行 esbuild（pnpm-workspace.yaml）
pnpm dev            # 开发 → http://localhost:5199
pnpm build          # 类型检查 + 生产构建
pnpm preview        # 预览已构建版 → http://localhost:4199（手机同网段可开）
```
首次启动在页面点「导入内置词库」（核心200词 + 册2），数据存浏览器 IndexedDB，离线可用。
自检：`node test-parse.ts`（词表解析）/ `node test-srs.ts`（记忆算法）/ `node test-smoke.mjs`、`node test-quiz.mjs`（真实 headless Chrome 冒烟，需 4199 在跑）。
